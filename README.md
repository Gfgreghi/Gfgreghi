## Projeto em destaque

### Sistema WMS — Gerenciamento de Estoque

API REST desenvolvida com Python e FastAPI para o gerenciamento de itens e corredores de estoque.

O projeto reúne práticas de desenvolvimento back-end, persistência de dados, autenticação, autorização e conteinerização.

**Principais funcionalidades**

- <img src="https://api.iconify.design/lucide/package.svg?color=%23800020" width="16" height="16" alt=""> Gerenciamento de itens e corredores de estoque.
- <img src="https://api.iconify.design/lucide/lock-keyhole.svg?color=%23800020" width="16" height="16" alt=""> Autenticação de usuários com JWT.
- <img src="https://api.iconify.design/lucide/shield-check.svg?color=%23800020" width="16" height="16" alt=""> Controle de acesso baseado em papéis e permissões (RBAC).
- <img src="https://api.iconify.design/lucide/database.svg?color=%23800020" width="16" height="16" alt=""> Persistência de dados com SQLAlchemy e MySQL.
- <img src="https://api.iconify.design/lucide/git-branch.svg?color=%23800020" width="16" height="16" alt=""> Versionamento do esquema do banco de dados com Alembic.
- <img src="https://api.iconify.design/lucide/containers.svg?color=%23800020" width="16" height="16" alt=""> Aplicação e banco de dados em serviços separados com Docker Compose.
