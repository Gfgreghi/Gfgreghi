## Projetos em destaque

### Sistema WMS — Gerenciamento de Estoque

API REST desenvolvida com Python e FastAPI para o gerenciamento de itens e corredores de estoque.

O projeto é um ambiente de prática para aplicar conceitos de desenvolvimento back-end, persistência de dados, autenticação, autorização e organização de aplicações.

**Principais funcionalidades**

- Gerenciamento de itens e corredores de estoque.
- Autenticação de usuários com JWT.
- Controle de acesso baseado em papéis e permissões (RBAC).
- Persistência de dados com SQLAlchemy.
- Versionamento do esquema do banco de dados com Alembic.
- Aplicação e banco de dados em serviços separados com Docker Compose.
